I’m an Agentic Product Engineer. I care about software that helps people finish what they came to do, gives agents clear ways to use the product when that helps, and stays dependable enough to run every day.

That shows up in how I work: product thinking before implementation, enough technical depth to make good tradeoffs, and design sensibility so the experience stays intuitive as the system grows. I’ve spent more than fifteen years shipping software, including twelve-plus years on 0→1 products with startups and growth-stage teams across FinTech, Web3, and AI.

Recently I’ve been building multimodal AI products where the interface has to earn trust. At LegalAgent I shipped voice and chat in a React Native Expo app—retrieval for case context, document summaries, and procedural guidance in Spanish and English, plus an admin layer for prompts and document categorization. Attorney feedback directly changed persona and tool calling in the client, which reinforced something I already believe: agent features need the same iteration loop as any other product surface.

I’m based in Costa Rica and work with distributed teams across the Americas and globally. If you’re building something where human experience, agent access, and operational simplicity have to line up, I’d enjoy comparing notes.
