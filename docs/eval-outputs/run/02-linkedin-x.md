## LinkedIn

At LegalAgent I added a voice and chat assistant to their React Native app for case context, documents, and procedures—the same retrieval scope the mobile client needs day to day.

Chat runs through the Vercel AI SDK; voice uses OpenAI's Realtime API, with Tailwind on the multimodal UI. RAG supplied case context, document summaries, and procedural guidance in Spanish and English. Attorney feedback changed persona and tool calling in the Expo client, which is where those adjustments had to land.

I also built an internal admin dashboard with TanStack Start: Microsoft SSO, system prompt management, and document categorization for RAG retrieval.
