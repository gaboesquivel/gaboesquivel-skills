# AGENTS.md

Gabo Esquivel Agent Skills catalog. One skill: `gabo` (identity, voice, and writing method).

```
skills/gabo/SKILL.md
```

`name` in frontmatter must equal the folder name. Description is a single line.

Install:

```bash
bunx skills@latest add gaboesquivel/gaboesquivel-skills --skill gabo
bunx skills@latest add . --skill gabo
```

Run `bun run validate` before push.
